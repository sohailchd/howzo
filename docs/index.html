How it works

No LLM, no embeddings, no cloud. A search index over what you already have.

  1. 01 scan Indexes everything actually installed: brew, npm, pipx, uv, system binaries with man pages, your own scripts, even npx packages you've used in the past. ~1,200 tools, 2–3 minutes, once.
  2. 02 match FTS5 BM25 + a word-boundary token-coverage re-rank. kill never matches skill; port never matches report.
  3. 03 answer The top tool, its one-liner, and the help lines most relevant to your question. Offline, ~20 MB of RAM, standard library only.

What it indexes

The differentiator: howzo indexes your machine, not a static corpus of popular commands. If it's installed, howzo knows it.

brew
formulae, versions, descriptions
npm
global packages + the binaries they install
pipx
packages + provided binaries (crwl → crawl4ai)
uv
uv tool installs
scripts
~/bin and ~/.local/bin, one-liner from the script header
system
/usr/bin + /usr/sbin + /usr/local/bin via man pages (Unix)
path
executables on PATH — System32, Program Files (Windows)
npx
npx / bunx / pnpm dlx packages mined from shell history
custom
anything you register with howzo add — internal CLIs and the like

Zero models. Fully local.

No accounts, no API keys, no telemetry. The network is only touched while scanning, to fetch package descriptions from npm and PyPI. Answering is 100% offline — your questions never leave the box.

Speaks MCP

Point any MCP client at howzo mcp and your assistant can ask the same questions you can: howzo_ask, howzo_whatis, howzo_list over stdio.


// mcp config
{
  "mcpServers": {
    "howzo": { "command": "howzo", "args": ["mcp"] }
  }
}

Commands

One binary, eight verbs.

howzo <query>ask in plain English (implicit ask)
howzo scan [--deep]rebuild the inventory; --deep also captures --help text for every tool
howzo ask "query"same as <query>
howzo whatis <tool>reverse lookup: what is this tool for?
howzo deep <tool>capture --help / man for one tool on demand
howzo add <name> "desc"register a tool the scanner can't see (survives rescans)
howzo list [--source S]browse the inventory
howzo mcprun as a stdio MCP server
howzo dbshow the database path
